# Archived Documentation

This folder contains historical planning and migration documents that were created during the development of the DAD monorepo. These documents are kept for reference but do not reflect the current state of the project.

## Contents

### Planning Documents

- **PROJECT_PLAN.md** - Original 6-week project plan for building a simple VSCode extension
  - **Status**: Historical - The actual implementation far exceeded this initial plan
  - **Context**: Created at project inception, describes basic React Flow integration
  - **Note**: The project evolved into a full monorepo with 3 production apps

- **MONOREPO_MIGRATION_PLAN.md** - Plan for migrating to monorepo structure
  - **Status**: Completed - Migration was successful
  - **Context**: Describes the architecture decisions and migration strategy
  - **Outcome**: Successfully migrated to Turborepo-based monorepo

### Merge Documentation

These documents track various merge operations during development:

- **MERGE_RESOLUTION.md** - General merge conflict resolutions
- **MERGE_RESOLUTION_SUMMARY.md** - Summary of merge resolution process
- **MERGE_RESOLUTION_SVG.md** - SVG rendering feature merge
- **MERGE_SUMMARY.md** - Overall merge operation summary
- **FINAL_MERGE_COMPLETE.md** - Final merge completion notes
- **FINAL_MERGE_SUMMARY.md** - Summary of final merge

## Why These Are Archived

1. **Historical Context Only**: These documents describe planning phases or past operations
2. **Superseded by Reality**: Actual implementation diverged significantly (in a good way!)
3. **Outdated Information**: Project structure and features have evolved
4. **Completed Migrations**: Monorepo migration and merges are long complete
