# Changesets

This folder contains changeset files for versioning packages in the monorepo.

## Usage

To add a changeset:

```bash
pnpm changeset
```

To version packages:

```bash
pnpm changeset version
```

To publish packages:

```bash
pnpm changeset publish
```

Learn more at [changesets.dev](https://github.com/changesets/changesets)
